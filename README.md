# Paulo Ramão — Site Institucional

Website institucional desenvolvido para **Paulo Sérgio Ramão**, terapeuta católico, com o objetivo de apresentar seu trabalho, serviços oferecidos e facilitar o contato com novos pacientes.

O projeto foi **refeito e modernizado**, buscando uma experiência mais profissional, acolhedora e intuitiva, com uma interface limpa e responsiva para diferentes dispositivos.

## ✨ Funcionalidades

* Apresentação profissional do terapeuta
* Seção "Sobre mim"
* Terapia individual
* Terapia para casais
* Perguntas frequentes (FAQ)
* Informações sobre atendimento presencial e online
* Formas de contato
* Layout responsivo para desktop, tablet e dispositivos móveis
* Navegação simples e intuitiva

## 🎨 Objetivo do projeto

O principal objetivo foi transformar a presença digital do profissional em uma experiência mais **moderna, confiável e acessível**, mantendo uma identidade visual acolhedora e alinhada à proposta do trabalho terapêutico.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript

Projeto desenvolvido como parte do meu portfólio de desenvolvimento web.
